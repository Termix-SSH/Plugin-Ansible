<h1>Ansible</h1>

<p>Run Ansible playbooks and ad-hoc commands from a control host, with an inventory made from your Termix hosts</p>

</div>

<br />

## Overview

Ansible runs playbooks from a control host you already have in Termix. Each control host gets its own tab for its playbooks, runs, ad-hoc commands and facts.

Read the [docs](https://docs.termix.site/plugins/ansible) to set it up and use it.

<br />

## Features

- Edit the playbooks in a project folder on the control host
- Run playbooks with check mode, diff, tags, limit and extra vars
- Use your Termix hosts and folders as the inventory
- Live run output, a recap per host and run history
- Run ad-hoc modules on any hosts
- Gather and read facts from hosts
